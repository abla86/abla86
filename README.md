## Repository strategy

The GitHub account is being **curated rather than expanded**.

- One canonical implementation per capability.
- Strong systems remain visible.
- Training exercises and superseded experiments are archival material.
- Private work stays private when it contains unfinished or sensitive material.
- Public claims point to executable code, tests, CI evidence or an explicitly bounded prototype.
