## Featured project

### Azure Kubernetes Showcase

A deliberately small Azure/AKS platform showcase covering:

- .NET APIs and React/TypeScript
- Terraform and Bicep
- AKS with Azure CNI Overlay, NetworkPolicy and Workload Identity
- Kubernetes Gateway API
- GitHub Actions, OIDC and ACR
- CodeQL, Trivy, SBOM and IaC validation
- OpenTelemetry and Day-2 troubleshooting
- Controlled resilience and security demonstrations

Repository: https://github.com/abla86/azure-kubernetes-showcase

## Engineering approach

I prefer implementations that can be inspected and verified over claims that depend on screenshots or undocumented runtime state. Architecture decisions, operational trade-offs and verification boundaries are documented alongside the code.
