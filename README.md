## How I work

**build → test → validate → document**

I distinguish between:

- **implemented** — the functionality exists in code
- **demonstrated** — the functionality can be inspected or run
- **verified** — tests or other evidence support the claim

The goal is simple: **make the work inspectable rather than relying on a list of keywords.**
