# Security Policy

## Scope

This repository is a public portfolio/profile repository. It does not intentionally contain production credentials, secrets, or confidential healthcare information.

## Reporting a security issue

Please do not publish sensitive details in a public issue. Report suspected security problems privately through GitHub's available private reporting mechanism for this repository, where enabled.

## Data boundary

Portfolio examples and demonstration projects must use synthetic or non-confidential data. No patient-identifying information should be committed.
